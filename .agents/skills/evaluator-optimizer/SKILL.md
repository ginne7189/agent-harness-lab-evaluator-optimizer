# Evaluator-Optimizer Skill

## 목적

생성 결과를 품질 기준으로 평가하고, 구체적인 피드백을 다음 수정 입력으로 사용해야 할 때 사용합니다. 단순 통과·거절만 필요하다면 Verifier만으로 충분합니다.

## 실행 순서

1. Generator가 1차 결과를 만듭니다.
2. Evaluator가 고정 기준으로 결과를 검사합니다.
3. `pass`이면 결과와 평가를 저장합니다.
4. `revise`이면 피드백을 다음 Generator 입력에 넣습니다.
5. 반복 횟수를 증가시키고 다시 평가합니다.
6. 한도에 도달하면 사람 확인으로 끝냅니다.

## 완료 조건

정상 결과뿐 아니라 정보 부족·중단·사람 확인 결과도 정해진 Contract와 함께 남깁니다.
